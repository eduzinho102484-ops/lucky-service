# 🔧 Lucky Service — Assistência Técnica

Site institucional desenvolvido para a Lucky Service, empresa especializada em conserto, instalação e manutenção de eletrodomésticos.

## 🚀 Sobre o projeto

O objetivo é apresentar os serviços da empresa de forma profissional, facilitar o contato com clientes e permitir solicitações de orçamento diretamente pelo WhatsApp.

## ✨ Funcionalidades

- Interface moderna e responsiva.
- Apresentação dos serviços oferecidos.
- Galeria de imagens.
- Botões de contato integrados ao WhatsApp.
- Formulário para solicitação de orçamento.
- Animações e efeitos visuais.
- Navegação adaptada para dispositivos móveis.

## 🛠️ Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- CSS

## 🎯 Objetivo

Desenvolver uma presença digital profissional para uma empresa de assistência técnica, melhorando a apresentação dos serviços e facilitando a comunicação com potenciais clientes.

## 👨‍💻 Desenvolvimento

Projeto de desenvolvimento web com foco em interface, responsividade, experiência do usuário e conversão de visitantes em contatos comerciais.
